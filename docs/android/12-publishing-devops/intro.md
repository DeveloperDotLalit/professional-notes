## 📋 Overview
Writing the code is only 50% of the job. Shipping it to users safely and reliably is the other 50%. This module covers **CI/CD** pipelines, **App Bundles**, **Play Console** management, and **Semantic Versioning**.

## 🎯 Learning Objectives

1.  Set up a **GitHub Actions** pipeline to build and test your app on every PR.
2.  Understand **Play App Signing** and why you should use it.
3.  Manage `versionCode` vs `versionName` automatically.
4.  Distribute internal builds via Firebase App Distribution.

## 📚 Topics Covered

- **CI/CD**: Continuous Integration/Deployment.
- **Signing**: Keystores, Aliases, Secrets management.
- **App Bundles**: Dynamic Delivery.
- **Build Types**: Debug, Release, Staging.
