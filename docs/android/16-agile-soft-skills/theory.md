## The Agile Manifesto (Engineer's Translation)

1.  **Individuals and iterations over processes and tools**.
    *Translation*: Don't let Jira configuration stop you from talking to the designer sitting next to you.

2.  **Working software over comprehensive documentation**.
    *Translation*: Ensure the app builds and runs. A 50-page wiki is useless if the APK crashes.

3.  **Customer collaboration over contract negotiation**.
    *Translation*: Talk to the Product Manager daily. Don't build exactly what the spec says if you know it's a bad UX. Suggest better ideas.

4.  **Responding to change over following a plan**.
    *Translation*: Requirements change. Don't get angry. Adapt the architecture to be flexible.

## Key Metrics

- **Velocity**: Average Story Points completed per Sprint. Ideally stable.
- **Cycle Time**: Time from "Start Coding" to "Merged to Prod". Lower is better.
- **Lead Time**: Time from "Ticket Created" to "Merged to Prod".
- **Code Churn**: Percentage of code rewritten recently (High churn = unstable requirements or bad design).

## The Definition of Done (DoD)
A checklist to agree when a ticket is "Done".

- Code Written.
- Tests Passed.
- Reviewed by Peer.
- QA Verified.
- Merged to Main.
- Feature Flag enabled (optional).
