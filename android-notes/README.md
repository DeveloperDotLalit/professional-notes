# Android Development: From Junior to Staff Engineer

Welcome to the **Complete Android Syllabus**.
This repository is a "Book-as-Code" project designed to take you from writing basic Activities to architecting scalable, production-grade applications.
It goes deep into Internals (Bytecode, Binder, V-Tables) and high into Soft Skills (Agile, Ownership).

## 🗺️ The Roadmap

### Phase 1: The Core
- **[Module 01: Kotlin Basics](../module-01-kotlin-basics/intro.md)** - Memory, Bytecode, Functional Patterns.
- **[Module 02: Android Internals](../module-02-android-fundamentals/intro.md)** - Binder, Looper, Zygote, Rendering.
- **[Module 13: OOPS Foundations](../module-13-oops-foundations/intro.md)** - Stack/Heap, Polymorphism, Composition.
- **[Module 14: SOLID Principles](../module-14-solid-principles/intro.md)** - SRP, OCP, LSP, ISP, DIP in Android.

### Phase 2: Architecture & UI
- **[Module 06: Jetpack Compose](../module-06-ui-compose/intro.md)** - Slot Table, Snapshots, Modifiers.
- **[Module 03: Jetpack Components](../module-03-jetpack-components/intro.md)** - ViewModel, WorkManager, Navigation.
- **[Module 04: Architecture](../module-04-architecture-mvvm-clean/intro.md)** - Clean Arch, MVVM, MVI, Dependency Injection.
- **[Module 15: Design Patterns](../module-15-design-patterns/intro.md)** - GoF Patterns, Builders, Factories, Adapters.

### Phase 3: Data & Networking
- **[Module 05: Advanced Kotlin](../module-05-advanced-kotlin/intro.md)** - KSP, Delegation, DSLs.
- **[Module 07: Networking](../module-07-networking-retrofit-ktor/intro.md)** - OkHttp Internals, Retrofit, Proxies.
- **[Module 08: Databases](../module-08-databases-room-datastore/intro.md)** - SQLite WAL, Room, DataStore.
- **[Module 09: Coroutines & Flows](../module-09-coroutines-flows/intro.md)** - Structured Concurrency, Channels, State Machines.

### Phase 4: Engineering Excellence
- **[Module 10: Testing](../module-10-testing/intro.md)** - Unit, Integration, UI, Fakes vs Mocks.
- **[Module 11: Performance](../module-11-performance-security/intro.md)** - Memory Profiling, R8, Security.
- **[Module 17: Debugging & Tools](../module-17-debugging-tools/intro.md)** - ADB, Logcat, Profilers, LeakCanary.
- **[Module 12: DevOps](../module-12-publishing-devops/intro.md)** - CI/CD, Signing, Release Management.
- **[Module 16: Agile & Soft Skills](../module-16-agile-soft-skills/intro.md)** - Scrum, Estimation, Code Reviews, Career Growth.
