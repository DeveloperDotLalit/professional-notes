## 📋 Overview
Android Jetpack is a suite of libraries to help developers follow best practices, reduce boilerplate code, and write code that works consistently across Android versions and devices. We focus on the "Big Three": **Navigation**, **WorkManager**, and **Lifecycle-Aware Components**.

## 🎯 Learning Objectives

1.  Master **Single Activity Architecture** using the Navigation Component.
2.  Schedule reliable background tasks with **WorkManager** (even if the app is killed).
3.  Migrate from `LiveData` to `StateFlow` and understand the "Why".
4.  Implement `Paging 3` without losing your sanity.

## 📚 Topics Covered

- **Navigation Component**: Graphs, Deep Links, SafeArgs.
- **WorkManager**: Constraints, Chaining, Periodic Work.
- **LiveData vs Flow**: The great migration.
- **Paging 3**: Loading states, separators, caching.
- **SavedStateRegistry**: How Jetpack saves state for you.
