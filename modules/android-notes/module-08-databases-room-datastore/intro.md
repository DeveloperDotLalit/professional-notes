# Module 08: Databases (Room & DataStore)

## 📋 Overview
Data persistence is more than just saving strings. It's about data integrity, complex querying, and handling schema changes without crashing the user's app. We use **Room** (SQL abstraction) and **DataStore** (SharedPreferences replacement).

## 🎯 Learning Objectives
1.  Write complex SQL queries in Room (Joins, Full Text Search).
2.  Perform **Database Migrations** without data loss.
3.  Choose between **Proto DataStore** and **Preferences DataStore**.
4.  Understand the performance cost of database transactions.

## 📚 Topics Covered
- **Room Entities**: Tables, Primary Keys, Indices.
- **Relationships**: `@Relation`, `@Embedded`, 1-to-1, 1-to-Many.
- **Migrations**: Automated vs Manual.
- **DataStore**: Type-safe storage with Protocol Buffers.
