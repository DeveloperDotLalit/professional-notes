## 📋 Overview
Gone are the days of editing XML, finding IDs, and handling fragment transactions. **Jetpack Compose** is the modern, declarative toolkit for building logic-driven UI. This module covers not just how to build UI, but how to render it **efficiently**.

## 🎯 Learning Objectives

1.  Think forcefully in **Unidirectional Data Flow (UDF)**.
2.  Master the **State Handling** lifecycle (`remember`, `rememberSaveable`).
3.  Debug **Recomposition** issues (why is my row flashing?).
4.  Navigate complex **Side Effects** (`LaunchedEffect`, `derivedStateOf`).

## 📚 Topics Covered

- **Declarative vs Imperative**: The paradigm shift.
- **Recomposition**: When and why it happens.
- **Stability**: The `@Stable` contract and skipping.
- **Lazy Layouts**: `Recycler` is dead, long live `LazyColumn`.
- **Modifiers**: The order matters!
