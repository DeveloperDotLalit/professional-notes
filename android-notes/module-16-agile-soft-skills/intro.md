# Module 16: Agile & Soft Skills for Engineers

## Module Overview
You can write the best Kotlin code in the world, but if you can't ship it, you fail.
Software Engineering is a team sport.
This module is not for Scrum Masters. It is **Agile for Developers**.
It covers how to survive Standups, how to estimate without lying, how to review code without making enemies, and how to own your career.

## What You Will Learn
- **The Process**: Why we do Standups and Retros (and how to make them useful).
- **The art of Estimation**: Why hours are bad, and Story Points are better.
- **Code Review Etiquette**: How to give (and take) feedback like a Senior Engineer.
- **Ownership**: Moving from "Task Doer" to "Feature Owner".

## Prerequisites
- None. Just an open mind.
