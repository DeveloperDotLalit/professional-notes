# Module 11: Performance & Security

## 📋 Overview
A slow app is an uninstalled app. An insecure app is a lawsuit waiting to happen. This module covers how to profile your app to find jank, prevent memory leaks using LeakCanary, and secure your user's data using R8 and encryption.

## 🎯 Learning Objectives
1.  Identify **Memory Leaks** and fix them.
2.  Understand **Garbage Collection** events in Logcat.
3.  Configure **R8** for code shrinking and obfuscation.
4.  Implement **EncryptedSharedPreferences**.

## 📚 Topics Covered
- **Android Profiler**: CPU, Memory, Network.
- **LeakCanary**: Automatic leak detection.
- **Frame Metrics**: Why 16ms matters (60fps).
- **Security**: Network Security Config, SSL Pinning, Obfuscation.
