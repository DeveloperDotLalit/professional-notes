# Module 10: Testing Strategies

## 📋 Overview
"It works on my machine" is not an engineering standard. Testing ensures your app works today, tomorrow, and after that huge refactor. We cover Unit Testing (Logic), Integration Testing (Components), and UI Testing (End-to-End).

## 🎯 Learning Objectives
1.  Write fast, flaky-free **Unit Tests** using MockK.
2.  Test **Coroutines and Flows** without `Thread.sleep()`.
3.  Use **Robolectric** to test Android components on the JVM.
4.  Debug **UI Tests** in Espresso/Compose.

## 📚 Topics Covered
- **The Test Pyramid**: 70% Unit, 20% Integration, 10% UI.
- **MockK**: Mocking, Spying, and Verifying.
- **Coroutine Testing**: `runTest`, `UnconfinedTestDispatcher`.
- **Turbine**: Simpler Flow testing.
- **Dependency Injection**: Swapping implementations for Fakes.
