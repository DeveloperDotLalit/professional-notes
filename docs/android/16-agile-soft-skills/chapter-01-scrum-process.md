## 1. The Daily Standup (DSM)
**Goal**: Unblock the team.
**Anti-Pattern**: Using it as a status report to the Manager.
"Yesterday I did ticket 123. Today I will do ticket 124." -> **Boring**.
**Pro Approach**: Focus on Goal & Blockers.
"I merged the Login API. Today I'm wiring up the UI. **I am blocked by the missing Design Assets**—Designer, can we chat after?"
This signals urgency and collaboration.

## 2. Sprint Planning
**Goal**: Agree on what is feasible.
**Anti-Pattern**: Accepting everything Product asks for.
**Pro Approach**: Push back with data.
"Our velocity is usually 20 points. You are asking for 30. We need to cut scope."
It is your *duty* to protect the sprint goal.

## 3. Retrospective
**Goal**: Continuous Improvement.
**Anti-Pattern**: The "Blame Game" or "Silence".
**Pro Approach**: Blameless Root Cause Analysis (RCA).
"We missed the deadline not because John is slow, but because the API spec changed 3 times mid-sprint. Action Item: Freeze API specs before starting UI work."
